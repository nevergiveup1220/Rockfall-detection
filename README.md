# Rockfall-detection
# **DSI**

code for paper "Industrial Edge-Intelligent Real-Time Rockfall Detection for Open-Pit Mines via Dynamic-Convolution YOLOv10 and Nutcracker Optimization"


# Abstract

Rockfall detection on open-pit metal mine slopes is a safety-critical industrial informatics task that must run in real time on resource-constrained edge devices amid dust, vibration, and illumination changes. To meet these constraints, we develop DGN-YOLOv10, an industrial edge–intelligent object-detection model that delivers high precision with low latency. The method couples three design elements: (i) a dynamic-convolution (DyConv) feature-recognition strategy that strengthens subtle rockfall cues and suppresses look-alike background textures (validated via ablations and Grad-CAM); (ii) a lightweight C2f_G_D composite module that integrates Ghost operations to reduce parameters and FLOPs without sacrificing accuracy, enabling deployment on low-power edge hardware; and (iii) a Nutcracker Optimization Algorithm (NOA) that adaptively tunes the learning rate, outperforming cosine annealing by accelerating convergence and improving generalization for real-time inference. Field evaluations on an open-pit metal mine (Henan, China) show precision 96.99%, recall 96.07%, mAP_50 98.21%, and mAP_95 89.19% with 4.0 ms per-image inference, 2.8885 M parameters, and 7.8 GFLOPs. In a separate deployment at an iron mine (Xinjiang, China), the system provided 149 s early-warning lead time prior to a landslide event. These results indicate that DGN-YOLOv10 can serve as a practical building block for industrial cyber-physical early-warning systems, supporting reliable, low-latency rockfall monitoring at the edge and paving the way for edge–cloud orchestration in large-scale slope safety management.

## Training on Custom Dataset

If you wish to train the model on your own dataset, please follow the steps below to annotate and organize your data.

### 1. Annotation Tool
We recommend using **LabelImg** for image annotation.
* **Installation:** `pip install labelImg`
* **Launch:** Type `labelimg` in your terminal.

### 2. Annotation Format (**Important**)
This project requires annotations in **`.txt` format** (YOLO format).
1.  Open LabelImg.
2.  In the left sidebar, click the **"PascalVOC"** button to switch it to **"YOLO"**.
3.  Ensure the button now reads **"YOLO"**.
4.  Save your annotations. A `.txt` file will be generated for each image (e.g., `image_01.jpg` -> `image_01.txt`).

### 3. Directory Structure
Organize your custom dataset strictly as follows to ensure the code runs correctly:

```text
dataset/
├── images/          <-- Put your images here (.jpg, .png)
│   ├── img_001.jpg
│   ├── img_002.jpg
│   └── ...
├── labels/          <-- Put your .txt annotations here
│   ├── img_001.txt
│   ├── img_002.txt
│   ├── classes.txt  <-- Generated by LabelImg, contains class names
│   └── ...
└── ...
```
### 4.  Configuration (data.yaml)

Before training, you must configure the `data.yaml` file to point to your local dataset path.

1.  Locate or create the `data.yaml` file in the project root.
2.  Modify the file content as follows. **Note:** We recommend using **relative paths** (relative to the project root) or your own absolute paths.

```yaml
# Example data.yaml content

# Path to the dataset root directory (Optional but recommended)
path: ./dataset  

# Directories for training, validation, and testing images (Relative to 'path')
train: images/train
val:   images/val   # or use 'images/train' if you don't have a separate val set
test:  images/test

# Classes Configuration
nc: 1              # Number of classes
names:
  0: rockfall      # Class names
```


##  Training

To train the YOLOv10-DynamicConv model, use the `train.py` script.

### 1. Configuration
Before running the script, open `train.py` and update the file paths to match your local directory structure:

```python
# Update these paths in train.py
model_yaml_path = r'./ultralytics/cfg/models/v10/yolov10n_DynamicConvnsa.yaml'
data_yaml_path = r'./datasets/data.yaml'
```

### 2.Usage
Run the following command in your terminal: `python train.py`


### 3. Hyperparameters
You can adjust the training parameters in the model.train() function:
epochs: Number of training iterations (set to 5 for testing, recommended 100+ for convergence).
batch: Batch size. Increase this if you have more GPU memory.
workers: Set to 0 for Windows compatibility. Increase to 4 or 8 on Linux for faster data loading.
optimizer: Supports AdamW (default), SGD, Adam, etc.
project/name: Results will be saved to runs/V10train/test.


### 4. Pre-trained Weights
By default, the script trains from scratch. To use pre-trained weights (Transfer Learning):
Download the weights (e.g., yolov10n.pt).
Uncomment the pre_model_path line in train.py.
Use model = YOLOv10(model_yaml_path).load(pre_model_path).
